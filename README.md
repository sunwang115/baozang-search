## 💎 核心功能

- **自动化链接洗白**：已接入 **夸克网盘、百度网盘、阿里云盘、UC网盘、迅雷网盘**。批量导入他人分享链接，系统自动执行"转存至个人盘 -> 生成个人分享链 -> 替换入库"，实现收益权转移。
- **私有资源池**：资源存入本地 MySQL 数据库，支持后台批量管理、资源标注及分类管理，方便全网分发。
- **多维分发模式**：
  - **前台搜索**：极简搜索首页，优先展示本地资源，后聚合展示第三方 API 结果。
  - **标准接口**：提供公开 API，可对接微信机器人、小程序或其他资源导航站。
- **资源分类管理**：支持自定义资源分类，可配置外部数据源自动填充分类内容。

## ✨ 新增功能亮点

### 1. 前台图片资源封面展示

- 资源支持上传封面图片，前台以卡片形式展示资源海报
- 分类详情页采用网格布局，每个资源显示封面、名称、网盘类型

### 2. 后台网盘对接修复与 Token 验证

- 修复百度网盘 `bdstoken` 获取逻辑，参照心悦盘搜实现稳定获取
- 新增网盘凭证有效性验证，自动检测 Cookie/Token 是否失效
- 优化错误码处理，提供中文错误提示（如"无效登录"、"容量不足"等）

### 3. 网盘对接新增目录选择

- 夸克网盘支持目录选择功能，可浏览网盘文件夹树
- 支持设置默认转存目录和临时转存目录
- 不同网盘可独立配置存储路径，灵活管理资源存放位置

### 4. 后台新增分类管理

- 支持自定义资源分类（电视剧、电影、综艺、动漫等）
- 分类可配置 Font Awesome 图标、排序权重
- 支持绑定外部数据源（夸克影视榜），自动获取热门资源填充分类
- 分类详情页独立展示，支持分页浏览

### 5. 后台资源列表正常写入与编辑

- 修复资源在后台项目列表的写入逻辑，支持新增、编辑、删除
- 资源支持设置分类、封面图片、网盘类型、备注信息
- 批量导入功能支持一次性导入多条资源
- 资源搜索支持按标题模糊查询

### 6. 添加资源时支持封面图片

- 新增资源时可填写封面图片 URL
- 前台分类页和搜索结果以卡片形式展示封面
- 支持无封面时的默认占位图显示

### 7. 后台 API 对接特定网盘搜索

- 支持配置多个第三方搜索 API（如趣盘搜、狗狗盘搜等）
- API 支持按网盘类型筛选（夸克、百度、阿里等）
- 支持 JMESPath 响应解析规则，灵活适配不同接口格式
- API 状态自动检测，异常 API 自动禁用

### 8. 用户使用 API 时先转存再分享（二级分享）

- 前台搜索支持"查看模式"：用户点击后系统自动转存到个人网盘
- 转存成功后生成新的个人分享链接，实现收益转移
- 支持临时分享缓存（6小时），相同链接无需重复转存
- 转存失败自动回退到原始链接，保证用户体验

### 9. 对接心悦盘搜等其他网盘搜索

- 内置多个第三方搜索 API 配置（趣盘搜、狗狗盘搜、盘搜等）
- 支持对接心悦盘搜等外部资源站
- 搜索结果自动聚合去重，按响应时间排序
- 支持外部数据源缓存（2小时），减少 API 调用频率

## 🔌 API 接口说明

| 参数           | 描述    | 示例值                                             |
| ------------ | ----- | ----------------------------------------------- |
| `keyword`    | 搜索关键词 | `凡人修仙传`                                         |

## 🚀 快速开始

### 0. 环境要求

- **Python**: 3.8 及以上版本
- **MySQL**: 5.7 或 8.0+

### 1. 获取源码

将项目克隆到本地服务器：

```bash
git clone <你的仓库地址>
cd baozang
```

### 2. 创建虚拟环境 (推荐)

```bash
# 创建虚拟环境
python3 -m venv venv
# 激活环境 (Linux/Mac)
source venv/bin/activate
# 激活环境 (Windows)
# venv\Scripts\activate
```

### 3. 安装依赖

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. 环境配置 (.env)

将项目根目录的 `.env.example` 文件重命名为 `.env` 文件，填入以下配置：

```ini
# 系统密钥 (用于JWT签名)
SECRET_KEY = 请替换为你的JWT签名密钥（如随机字符串）

# MYSQL 数据库配置
DB_HOST = localhost
DB_PORT = 3306
DB_DATABASE = ucmao_search
DB_USER = root
DB_PASSWORD = 请替换为你的MySQL密码
DB_CHARSET = utf8mb4

# 管理员账号配置
ADMIN_USERNAME = admin
ADMIN_PASSWORD = 请替换为你的管理员密码
```

### 5. 初始化数据库

```bash
# 创建数据库
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS ucmao_search DEFAULT CHARACTER SET utf8mb4;"
# 导入表结构
mysql -u root -p ucmao_search < schema.sql
```

### 6. 启动应用

```bash
python app.py
```

访问 `http://localhost:5004` 即可进入系统。

### 7. Linux 一键部署 (可选)

项目提供了 `install.sh` 一键部署脚本，支持 Ubuntu/Debian/CentOS/Rocky/AlmaLinux：

```bash
chmod +x install.sh
sudo ./install.sh
```

脚本会自动安装依赖、配置 MySQL、创建系统服务、配置 Nginx 反向代理。

项目后台统一使用"云盘凭证"概念，不同平台需要填写的内容如下：

| 平台   | 后台字段                                         | 说明                         |
| ---- | -------------------------------------------- | -------------------------- |
| 百度网盘 | `百度网盘 Cookie`                                | 登录网页版后复制整段 Cookie          |
| 夸克网盘 | `夸克网盘 Cookie`                                | 登录网页版后复制整段 Cookie          |
| 阿里云盘 | `阿里云盘 Refresh Token`                         | 使用阿里云盘登录态提取 refresh\_token |
| UC网盘 | `UC网盘 Cookie`                                | 登录网页版后复制整段 Cookie          |
| 迅雷网盘 | `Refresh Token` + `Captcha Sign` + `User ID` | 3 个字段必须同时填写，缺一不可           |

## 💡 如何获取 Cookie / Token？

### 百度网盘 / 夸克网盘 / UC 网盘 Cookie

1. **登录网页版**：在浏览器打开对应平台官网并登录。
2. **进入开发者模式**：按下 `F12`，切换到 **Network (网络)** 标签页。
3. **刷新页面**：按 `F5` 刷新，在左侧列表中找到第一个请求。
4. **复制 Cookie**：在右侧 **Headers (标头)** 中找到 `Cookie:` 字段，复制整段字符串。
5. **完成配置**：登录后台，进入 `系统配置`，粘贴保存。

### 阿里云盘 Refresh Token

阿里云盘不是直接使用 Cookie，而是使用 `refresh_token`。你需要通过自己的抓包方式或现有工具提取登录态中的 refresh token，然后填入后台的 `阿里云盘 Refresh Token`。

### 迅雷网盘三件套

迅雷网盘需要同时准备：`refresh_token`、`captcha_sign`、`user_id`
